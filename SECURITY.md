# Security and public boundary

This repository is an offline clean-room technical case. It contains no live exchange connectivity,
credential input, deployment configuration, private prompt, trading strategy, or runtime data.

The examples accept only in-memory synthetic observations and return typed decisions. They are not a
remote-execution framework and should not be adapted for real-money execution without independent
security, regulatory, and operational review.

## Reporting a problem

Do not open a public issue containing credentials, private account information, or identifying execution
data. A private reporting channel will be selected before this repository is published. Until then, keep
any sensitive report offline and contact the repository owner through an already verified private channel.

## Supported surface

Only the synthetic examples, their tests, and the public-boundary scanner are in scope. The private ORINX
product and any external execution venue are outside this repository's security boundary.
